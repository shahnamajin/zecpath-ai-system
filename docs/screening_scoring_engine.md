# Zecpath Screening Scoring Engine

## Overview

The Screening Scoring Engine evaluates candidate screening responses using four parameters:

- Clarity
- Relevance
- Completeness
- Consistency

## Scoring Weights

| Parameter | Weight |
|---|---:|
| Clarity | 25% |
| Relevance | 30% |
| Completeness | 25% |
| Consistency | 20% |

Total:

100%

## Per-question Score

Each candidate answer receives a score from 0 to 100.

The weighted formula is:

Final Question Score =
(Clarity × 0.25)
+
(Relevance × 0.30)
+
(Completeness × 0.25)
+
(Consistency × 0.20)

## Overall Screening Score

The overall screening score is calculated by averaging the individual question scores.

Overall Score =
Sum of Question Scores / Number of Questions

The final result is normalized to a 0–100 range.

## Explainability

Each score includes explanations describing:

- Answer clarity
- Answer relevance
- Answer completeness
- Information consistency

## Integration

The engine consumes structured answer objects generated by the Day 25 Answer Understanding Engine.
