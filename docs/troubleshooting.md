# Zecpath AI ATS – Troubleshooting Guide

## 1. Overview

This document provides solutions for common errors and issues encountered while developing, testing, and running the Zecpath AI Applicant Tracking System (ATS).

The guide covers:

- Python environment issues
- API startup errors
- Import errors
- Circular imports
- Resume parsing issues
- ATS scoring issues
- Performance issues
- Noisy resume handling
- Stability testing

---
