# AI Data Entity Design

## Candidate Profile

Stores candidate information extracted from resumes.

Fields

- Personal Information
- Skills
- Education
- Experience
- Projects
- Certifications

---

## Job Profile

Stores structured information extracted from job descriptions.

Fields

- Job Title
- Required Skills
- Preferred Skills
- Experience
- Education

---

## Skill Entity

Represents an individual skill.

Example

Python

Java

SQL

Represents work history.

Company

Designation

Duration

Responsibilities
